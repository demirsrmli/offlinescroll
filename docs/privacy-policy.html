OfflineScroll privacy policy

OfflineScroll plays videos already stored on your Android device. All core features work on the phone without an account, network, server, or companion app.

Data on your device The app reads only the videos you permit. It uses their local filenames, duration, folder information, and file descriptors to show and play them. Likes, favorites, hidden-video flags, settings, selected-source references, and optional feed order/playback position remain in the app's private storage. The app does not copy your video library or modify, move, delete, or transcode original files. Thumbnails are held in a bounded memory cache, not permanently saved as frames.

The app can keep a consent-scoped private metadata index (up to 16 MiB) to reopen your library quietly. This index contains filenames and basic metadata only, never video bytes or permanently saved frames. Partial or revoked permission cannot reuse a previously broader cached library. Likes and repost-style saves are local records; the save action does not publish or share a video.

No collection or uploads The app has no internet or network-state permission. It has no ads, analytics, telemetry, online crash reporting, platform MediaMetrics reporting, account system, cloud storage, or remote database. Video content, names, watch history, settings, and identifiers are not sent outside the device by OfflineScroll.

Permissions and source selection You can permit the local device-video library, allow selected videos on supported Android versions, or choose individual local documents. Access can be denied, changed, or revoked in Android settings. The system picker may display cloud providers; OfflineScroll asks for local-only files and rejects unverified, cloud, virtual, or non-local sources. No unrelated image or write permission is requested.

Backups and deletion App backup is disabled and extraction rules exclude app records from supported Android backup/transfer paths. Device-vendor behavior outside these Android rules is outside the app's control. Clear local app data removes settings, flags, history, caches, and persisted file access grants. Your original videos are not deleted. On Android 13+ runtime media permissions are also queued for system self-revocation; on older Android versions manage the OS permission in settings.

Optional external source link The Source code action opens https://github.com/demirsrmli/offlinescroll through another app, only after you tap. No video information or identifiers are appended. That external app and website have their own network behavior and privacy policy. OfflineScroll does not embed or fetch repository content. Copying the URL works offline. This optional action is not required for browsing or playback.

Questions The intended public project is https://github.com/demirsrmli/offlinescroll. For security reports, use the private reporting method described in SECURITY.md after the maintainer has enabled it. Do not include personal videos, filenames, or credentials in public issues. No private contact address is published here.

Store publication The maintainer must host this policy at a public URL for the store listing and verify that it matches the final released build. The app itself does not need internet permission to display this packaged policy.
