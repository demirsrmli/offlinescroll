# OfflineScroll 0.2.0 sharing and privacy report

The real 0.1.0 project was preserved as a separate snapshot before updating the
working source. IDs and signing configuration are retained; code increased from
1 to 2. Original attachments and signing keys were not deleted or overwritten.
No production key was supplied, created, exported, or embedded.

## Shared content and exclusions

The source sharing copy excludes Git history, real local.properties,
keystore.properties, environment/credential files, keystores/private keys, IDE
caches, build outputs, APK/AAB binaries, user databases, private media, diagnostic
logs, heap dumps and local tooling. Compiled APK/AAB files are supplied separately.
The Gradle Wrapper JAR, required legal notices, and clean logo assets are retained.

The original supplied logos had author/identifier metadata. Version 0.1.0 removed
that metadata from sharing assets with decoded pixel equality; 0.2.0 retains those
same clean image bytes. No logo replacement or geometry change was made. Research
screenshots are private references and are not bundled. New control vectors are
original project assets; no Instagram icon or image license is assumed.

Source code, Gradle/XML/JSON/scripts/Markdown/legal text, image metadata, example
configuration and delivery documents are reviewed for secret/personal-data
patterns. Only obvious signing placeholders are shipped. The MIT notice uses the
public GitHub handle explicitly supplied for the project. Third-party notices
retain their original public attribution. No private value is reproduced here.
The final scan and archive results are recorded in the verification report and
SHA-256 list. Pattern scans are scoped checks, not proof that every possible
secret is absent. No earlier Git history was supplied for exposure analysis.
Previously published credentials must be revoked/rotated and removed from history;
.gitignore or deleting one working file does not undo exposure.

## Update summary

The Feed has a persistent TextureView and first-frame audio gate; orientation-
neutral limits and audio-only rejection; transparent actions, local Like/Save,
9:16 FIT, compact options and display-synchronized paging. Ordinary UI backgrounding
is separated from actual memory pressure. A first-run English privacy welcome
and consent-scoped metadata index reduce repeated loading interruptions. The
144 Hz window preference remains subject to display/OS limits. No runtime
dependency was added and no original video is copied or modified.

No INTERNET/network-state permission, backend, telemetry, platform MediaMetrics,
cloud backup, downloadable UI asset or user-content export is configured. Local
records and index remain private and excluded from backup/transfer. Data clearing
resets records/cache/grants and internal library consent without gallery writes.

Release signing reads only ignored local configuration or private environment
variables. Normal release fails without a key; an explicit opt-in creates an
UNSIGNED review bundle. The release is never silently signed with the debug key.
The test APK uses the same development certificate as the earlier delivery.

## Verification limits

36 automated tests pass, debug/release builds pass and both lint variants have
zero errors. The compiled manifest, bundle structure, signatures and 16 KiB
alignment are checked. Reliable physical-device decoding, 144 Hz performance,
airplane-mode playback and long-session memory measurements remain untested.
See VERIFICATION.md for the exact scope and owner release actions. No GitHub
upload, repository publication, store upload or public hosting was performed.
